# 公众号封面图提示词模板

封面要在两种裁切下都成立：文章卡片上的 **2.35:1 横幅**，以及转发/列表里的 **1:1 方图**。方图只取画面正中，所以主体必须紧凑、居中。默认风格是**极简**：一个视觉隐喻加最多一个短词，文字越少，模型画错字的概率越低，缩略图也越清楚。

## 先想清楚三件事

1. **一个隐喻**：用一个图形关系说出文章的核心转折，不要堆图标。例子：
   - 合并/统一：几个分散的小方块 → 一个大圆角方块（Tectonic：孤岛合成大陆）
   - 并行化：一条长的串行链 → 几条并排的短链
   - 解耦/拆分：一个整体方块 → 拆成两半，各自归位
   - 加速：长条进度 → 短条进度
   - 去中心热点：一个过热的中心节点 → 均匀分布的节点
2. **一个词**：通常是系统名或方法名（如 `Tectonic`、`InfiniFS`），逐字给出。不要放文章标题——标题在公众号里另有位置。
3. **配色**：白底 + 一个主色 + 一个点缀色。默认深蓝 `#1f4e9e` + 橙色 `#e8711a`，与 `to_wechat.py` 的默认主题色一致；如果文章换了 `--accent`，封面也换成同一个主色。

## 提示词模板

把 `{…}` 换成具体内容，原样交给生图后端：

```text
【用途】微信公众号文章封面，之后会裁成 2.35:1 横幅，并从正中裁出 1:1 方图作缩略图。
所有内容必须集中在画面正中，主体整体宽度不超过画面宽度的 55%，上下各留约 20% 纯色空白，左右各留约 15% 空白。
【画幅】横版宽图（如 1536x1024）。
【风格】极简扁平矢量风，纯白背景，只用 {主色} 和少量 {点缀色}；无渐变、无阴影、无纹理、无 3D。
【画面】{一句话描述隐喻，写清楚左边是什么、中间用什么连接、右边是什么}。
{主体上的文字位置}，用白色（或主色）粗无衬线字写 "{一个词}"。
【文字】除了 "{一个词}" 之外画面不要有任何其他文字、数字或符号。拼写必须是 {一个词}。
【禁止】不要标题栏、副标题、图标堆砌、人物、照片、水印、多余装饰。
```

### 示例（Tectonic, FAST 2021）

```text
【用途】微信公众号文章封面，之后会裁成 2.35:1 横幅，并从正中裁出 1:1 方图作缩略图。
所有内容必须集中在画面正中，主体整体宽度不超过画面宽度的 55%，上下各留约 20% 纯色空白，左右各留约 15% 空白。
【画幅】横版宽图（如 1536x1024）。
【风格】极简扁平矢量风，纯白背景，只用深蓝 #1f4e9e 和一点橙色 #e8711a；无渐变、无阴影、无纹理、无 3D。
【画面】左边 4-5 个大小不一的深蓝小方块（像散落的小岛），一条细的橙色箭头指向右边，右边是一整块深蓝大圆角方块（像合并后的大陆）。
大方块上用白色粗无衬线字写 "Tectonic"。
【文字】除了 "Tectonic" 之外画面不要有任何其他文字、数字或符号。拼写必须是 Tectonic。
【禁止】不要标题栏、副标题、图标堆砌、人物、照片、水印、多余装饰。
```

## 验收

生成后先看原图，再跑 `make_cover.py`，再看两张裁切结果：

- [ ] 唯一的文字拼写正确，没有多余文字、伪字或水印
- [ ] 背景是干净的纯色（`make_cover.py` 依赖背景色找主体；有纹理或渐变会让裁切失准）
- [ ] `make_cover.py` 报告里两张图都是 `content_fits: true`
- [ ] 1:1 方图缩到很小（约 100px）时主体仍然能认出来

不通过就改提示词重新生成（通常是让主体更紧凑、去掉多余元素），不要靠手工裁切硬救。
