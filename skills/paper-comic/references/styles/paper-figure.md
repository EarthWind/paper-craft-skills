# paper-figure — 论文框架图风

像一张重新设计过的顶会论文 Figure：专业、清楚、信息密度高，但比原论文图更适合传播。

## 氛围

- 像 NeurIPS / ICLR / Nature / Science 论文中的方法总览图
- 不是蓝图、不是海报、不是漫画
- 目标是让读者在30秒内理解论文核心方法

## 视觉规范

### 画布
- 白底或极浅灰底
- README 首屏优先横版 16:9 或 4:3
- 机制拆解图可用竖版 2:3

### 图元
- 干净的矢量感模块：圆角矩形、矩阵小格、token序列、分组框、编号步骤
- 箭头精确、方向明确，主路径比辅助路径更粗
- 允许使用小型热力图、曲线、结果缩略图、模块堆叠、对比路径

### 文字
- 无衬线字体，像论文图中的短标签
- 标注必须短：模块名、变量名、关键操作、1行解释
- 语言遵循用户确认：中文 / English / 双语

### 色彩
- 黑/深灰为主
- 只使用1-2个强调色，例如蓝+橙、青+紫
- 强调色用于核心贡献、关键路径或对比，不做装饰
- 每个强调色固定代表一个概念，按整组共用的颜色语义表分配（见 SKILL.md Step 4.1）；对比图中旧方法 / baseline 用中性灰
- 用了 2 个强调色时，加一行图例

## 封面 / 总览页版式

整组图的第 00 页固定用这个版式，让不同论文的图集看起来是同一个系列。横版 16:9。

```
┌──────────────────────┬───────────────────────────┐
│ 小标签：论文方法图解 · 共 N 张 │ 面板标题：一句话说出核心思路    │
│ 论文原标题（大、粗）            │                           │
│ 中文副标题：一句话说出做法       │   核心思路示意图             │
│ 作者 · 机构 年份               │   （占右栏主体）              │
│ ┌ 一句话 ────────────┐       │                           │
│ │ 2–3 行，含最关键结果  │       │                           │
│ └────────────────────┘       │                   图例    │
│ 核心组成：2–3 张概念卡片 + 图例  │                           │
│ 目录：两列，编号对应后续页       │                           │
├────────┬────────┬────────┬────────┤
│ 数字卡   │ 数字卡   │ 数字卡   │ 数字卡   │
└────────┴────────┴────────┴────────┘
左下：引用（作者, 标题, 会议/机构 年份）            右下：页码 00 / NN
```

- **左栏（约 45%）**
  - 小标签"论文方法图解 · 共 N 张"用黑或灰，不用强调色
  - 论文原标题保留原文；副标题用用户确认的语言，一句话说出"做了什么"
  - "一句话"框用中性灰底，2–3 行，最后一句给出最关键的结果
  - 核心组成卡片 2–3 张（如"预训练 / 微调""模型 / 提示"），每张用它所代表概念的颜色，旁边带图例；"三块积木"这类卡片同理
  - 目录两列，条目与后续页一一对应
- **右栏（约 55%）**：一张讲"核心思路"的示意图，不是完整架构图（完整架构放第 01 页）
  - 必须有真实可视化元素：token 序列、注意力弧线、同一模块接不同输入 / 输出、before / after 对比等；不要只画几个抽象方块
  - 面板标题直接说结论（如"同一个模型、同一组参数：换一段提示，就换一个任务"）
  - 用到 2 个及以上强调色时带图例
  - 示意中的格式或数值若不是原文，用一行小字注明"示意"
- **底部数字卡（4 张）**：大数字 + 名称 + 一行对照（如"此前最佳 77.6，+8.9"）
  - 数字必须来自原文
  - 数字颜色按它所属的概念（通常都是模型的颜色）；不要为了好看让几张卡片交替换色
- **页脚**：左下引用，右下页码"00 / NN"

## 生成原则

- 可以参考论文原始框架图的概念，但必须重新组织信息，不能复刻原图
- 概述图要覆盖输入、核心模块、输出和关键贡献
- 细节图要把一个机制拆清楚，不要把所有东西塞进一页
- 结果图只放最有说服力的一条结果，不做完整实验表格

## 禁止

- 不要蓝底白线工程图纸风
- 不要3D渲染
- 不要用大段文字解释
- 不要复制论文原图布局
- 不要做成营销海报或只有大标题的空封面；封面按上面的版式，信息要实
